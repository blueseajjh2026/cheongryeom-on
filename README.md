# 청렴ON 최종본 - CI·캐릭터 적용 / 실명 수험등록

중·고등학생 대상 QR 기반 모바일 청렴역량 인증 프로그램 최종형입니다.

## 주요 변경
- 학생은 닉네임이 아니라 **실제 학생 이름을 정자로 입력**합니다.
- 학생 이름은 교사용 수험명단과 디지털 자격증에 표시됩니다.
- 학생 간 화면에는 다른 학생 이름을 공개하지 않습니다.
- 이름 정보가 포함되므로 수업방 참여코드를 **6자리 숫자**로 강화했습니다.
- 전화번호·이메일은 입력받지 않습니다.
- 교사가 수업 종료 후 `수업방 종료·삭제`를 누르면 해당 수업방의 이름·응답·실천약속을 함께 삭제합니다.

## 공식 CI·캐릭터 적용 원칙
업로드된 원본 파일을 `assets/official/`에 그대로 복사해 사용합니다.
- 이미지 파일 자체를 편집하지 않음
- 색상 변경 없음
- 좌우 반전·회전 없음
- 선 굵기 변경 없음
- 캐릭터 구성요소 위치 변경·겹침 없음
- 그림자·필터·색상 보정 없음
- 복잡한 패턴 배경 위 배치 없음
- CSS에서는 **가로세로 비율을 유지한 상태의 브라우저 표시 크기 조절만** 사용
- 두 캐릭터가 함께 있는 `기본동작_함께.png`는 한 장의 원본 이미지로 사용

## 실제 실시간 기능
- 교사용 PC 수업방 개설 / QR 자동 생성
- 학생 휴대폰·태블릿 실시간 참여
- 교사가 단계 변경 시 학생 화면 동기화
- 실시간 응답 집계
- 과정평가 최초 선택 → 학급 결과 → 토론 → 재선택
- 판단 변화율 자동 산출
- 학생별/학급 6대 청렴역량 진단
- 교사용 학생 수험명단 및 과정 진행상태
- 디지털 청렴 서포터 / 청렴 리더 자격증
- 교사용 CSV 결과 저장

## 1회 서버 설정
`SETUP.html` 안내대로 Firebase Anonymous Authentication + Realtime Database를 연결하고 `js/firebase-config.js`에 웹 설정값을 입력하세요.

## 자격판정
- 전 과정을 완료하면 기본 `청렴 서포터`
- 종합 85점 이상 + 실기 80점 이상이면 `청렴 리더`

## 주의
본 프로그램의 자격은 실제 국가기술자격이 아닌 교육용 청렴역량 인증입니다.
국민권익위원회·국가청렴권익교육원의 공식 서비스가 아닌 국민참여 청렴공모전 출품용 프로그램입니다.
